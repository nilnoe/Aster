# ADR-018 — 基础功能完善方向（Beta V0.2 规划）

- **Status:** Accepted
- **Date:** 2026-08-02
- **Version:** 1.0
- **新增 Public API:** 0（方向性决策；实现切片各自走 ADR / 缺陷流程）
- **影响模块:** roadmap、app/、core/（规划与后续切片）
- **是否违反 Single Responsibility:** 否
- **是否增加循环依赖:** 否

---

## 决策

1. **深浅色不跟随系统**：编辑器保持固定深色启动态（现状），系统 appearance 不接线；
   主题可编程能力由 Lua 提供（ADR 总纲 Layer 3；Theme 模型已在 Core，ADR-010）。
   Roadmap 原 T-014 的「深浅色跟随」移除。
2. **渲染质量优先**：下一个渲染切片做 sRGB + gamma 校正（T-016）——与系统文本渲染
   （TextKit 类）相比，最大可感知差距在抗锯齿边缘的混合；改动集中在管线，收益全文本。
3. **光标是 T-013 验收缺口**：静态光标当前不可见（根因：图集纯白像素画到错误的纹理行，
   BUG-002），先按缺陷流程修复可见性，再加闪烁（T-017）。
4. **基准体系前置**（T-021）：性能断言不可信（WORKFLOW「Benchmark 是常态」）；String
   是否够用、是否换 Rope/Gap 是 ADR-006 的基准驱动决策——criterion 基线穿插建立，
   不阻塞功能切片。
5. **编辑打磨按使用频率排序**：DeleteForward / 词级移动（T-018）、双击选词 / 三击选行
   （T-019）、平滑滚动 / IME 候选框定位（T-020）。

## 原因

- **深浅色（Rule 9 复杂度预算）**：appearance 接线（系统通知观察、颜色映射、图集 /
  顶点色重建）为一个 Beta 早期低价值能力引入状态；极简启动态是项目哲学
  （启动即一个空白、安静的 Buffer，ADR 总纲 1）。未来 Lua 一行配置可补
  （`theme.dark = true`），顶点色已支持任意颜色（ADR-016），不预留耦合。
- **渲染质量**：用户可感知差距集中在管线本身（gamma / 混合），T-016 是
  「成本低、收益全文本」的切片，优先于功能堆叠。
- **基准前置**：存储结构替换必须有数据支撑（ADR-006 已确定项），没有基线就换结构
  是猜测（Rule 9）；基准体系拖延越久，决策窗口越窄。
- **打磨排序**：删除与词移动是高频编辑动作；选词是文本编辑的基本手势；平滑滚动与
  IME 定位是「像正常 App」的最后一块拼图。

## 审计

### Single Responsibility

规划性 ADR，只记录方向与原因，不引入模块；实现切片的 SRP 由各自 ADR 负责。

### 循环依赖

无代码影响；后续切片仍保持 app → bridge → core 单向。

## 新增 Public API

无。

## 影响模块

- **roadmap** — T-014 重划（移除深浅色跟随，保留剪贴板 / 拖放 / 文档选择器）；
  新增 Phase 3 打磨任务（T-016 ~ T-021）；Overlay 与发布任务顺延并重新编号
  （T-022 ~ T-028）。
- **app/** — T-016 渲染管线、T-017 光标、T-018 ~ T-020 编辑打磨切片。
- **core/** — T-021 基准体系可能引入 criterion（dev-dependency，届时走 Rule 7 / 8）。

## 复杂度预算（宪法 Rule 9）

1. **增加了哪些复杂度？** 规划任务 6 项 + 方向决策记录；0 行代码。
2. **是否是永久性的？** 方向决策长期有效（深浅色「不跟随」直到 Lua 主题切片改变它）；
   任务编号随开发调整。
3. **有没有更简单但同样满足需求的方案？** 不记录方向直接开发——每个切片重新争论
   深浅色与优先级，协调成本更高；Roadmap 是既定决策载体（WORKFLOW）。

结论：0 模块 / 0 API / 0 依赖，未触及红线。

## 备注

- 「不跟随系统」不是永久拒绝：Lua 主题切片落地后，一行配置即可让用户选择深 / 浅色；
  系统跟随作为 Lua 可编程能力的一种输入，不再作为内建行为。
- 各任务实现时若引入新 Public API / 依赖，按宪法 Rule 4 / 7 / 8 分别走 ADR。
